# payment-hub-ee
Payment Hub Enterprise Edition middleware for integration to real-time payment systems.

## Requirements

- **Java 21** (LTS)
- **Gradle 8.5+** (via included Gradle Wrapper)
- **Maven 3.8+** (for Maven-based builds)

## Build

### Gradle
```bash
./gradlew clean build
```

### Maven
```bash
mvn clean package
```
